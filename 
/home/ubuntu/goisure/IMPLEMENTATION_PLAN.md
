
# Goisure Underwriting Analysis Implementation Plan

## Overview
Implement 3 major workstreams to enhance underwriting analysis, member table UX, and workflow.

## Workstream 1: Underwriting Analysis & AI Capabilities

### 1.1 Claim Type Breakdown
- **Charts needed**: Pie chart (claim type distribution), stacked bar (cost by type)
- **API endpoint**: `GET /api/cases/{id}/claim-breakdown`
- **Data aggregation**: Group claims by diagnosis category (chronic, accident, preventive, maternity, surgery, other)

### 1.2 High-Impact Claim Flagging
- **Backend**: Tag severe claims (cancer, major surgery, organ transplant)
- **UI**: Red badges in member table, severity indicator in charts

### 1.3 Direct Plan Comparisons
- **Modal/sidebar**: Show Essential vs Standard vs Enhanced side-by-side
- **Metrics**: Premium/lac, sum insured range, features, loading/discount

### 1.4 Historical Trendlines
- **Data**: Loss ratio, claim frequency over 24 months
- **Charts**: Line charts with forecast

### 1.5 Industry Benchmarking
- **Static data**: IRDAI/NAIC benchmarks (65% LR for IT services)
- **API endpoint**: `GET /api/benchmarks/{industry}`

## Workstream 2: Member Data Table UX

### 2.1 Pagination
- **Rows per page**: 10-15
- **Backend**: `/api/cases/{id}/members?page=1&limit=15&sort=...`
- **UI**: MUI DataGrid or AntD Table with server-side pagination

### 2.2 Search & Filter
- **Debounced search**: Name, employee ID
- **Filters**: Risk tier, claim status, date ranges, chronic status
- **Backend**: MongoDB queries with indexes

### 2.3 Predictive Risky Member Alerts
- **New ML endpoint**: `POST /api/cases/{id}/risk-predict`
- **Features**: Past claims, age, conditions, family history
- **Model**: Fast Random Forest or Logistic Regression (scikit-learn)
- **Output**: Risk probability 0-100, flag high-risk (>70%)
- **UI**: Red badge, filter by high-risk

## Workstream 3: Layout & CTA Redesign

### 3.1 Remove "Run AI Analysis" button
- Auto-trigger AI on case view
- Background job with status indicator

### 3.2 Navigation Restructure
- Move Back button to top-left
- Add breadcrumbs: Portfolio → Case → Analysis

### 3.3 Primary CTA: Submit to Underwriter
- **Button**: "Submit to Underwriter" (primary, fixed at bottom)
- **Modal**: Add notes/comments before submission
- **Flow**: 
  1. Click → Open modal
  2. Add notes
  3. Submit → Status = "Pending Underwriter Review"
  4. Notify underwriter team
  5. Audit log
- **Remove**: Bottom "Share quotation" and "Regeneration" buttons
