
# Case Detail Page Redesign - Implementation

## Overview

This implementation provides a complete redesign of the GMC Case Detail page, similar in quality and functionality to the AI Analyse Hub. The solution includes:

- **6 Tab Views**: Summary, Enrollment, Claims, Matching, Insights, Underwriting
- **Interactive Workflow**: Progress tracking with resume capability
- **Auto-Save**: Draft preservation every 30 seconds
- **Context-Aware Actions**: Dynamic action bar based on case state
- **Responsive Design**: Works on mobile, tablet, and desktop

## Key Features

### 1. Progressive Workflow
- Visual timeline showing completed/pending steps
- Click any step to resume from that point
- Smart next-action suggestions

### 2. Data Visualization
- **Enrollment Tab**: Sortable/filterable member table
- **Claims Tab**: Claim history with match status
- **Matching Tab**: Claim-to-enrollment mapping
- **Insights Tab**: AI risk analysis & recommendations
- **Underwriting Tab**: Premium impact & recommendations

### 3. Auto-Save & Resume
- Draft state saved every 30 seconds
- Resume detection on page load
- Manual save available anytime

### 4. Real-Time Updates
- Background polling (30s) for job completion
- Optimistic UI updates
- Toast notifications for completions

## API Endpoints

### New Endpoints

#### GET /api/cases/{case_id}/detail
Returns complete case data for the detail view:
```typescript
{
  case: { ... },
  enrollment: { total_count, data, columns, summary },
  claims: { total_count, total_claimed, data, matched_count, match_rate },
  matching: { status, match_rate, match_results, quality },
  analytics: { ... },
  metrics: { ... },
  insights: { ai_insights, risk_indicators, recommendations },
  underwriting: { premium_impact, loss_ratio, recommended_tier },
  workflow: { current_step, completed_steps, next_action, progress_percentage }
}
```

#### POST /api/cases/{case_id}/save-draft
Save draft state:
```typescript
Body: { "data": {...}, "step": "string" }
Response: { "success": true, "saved_at": "datetime", "step": "string" }
```

#### GET /api/cases/{case_id}/resume
Get resume point:
```typescript
Response: {
  "next_step": "upload|match|ai_process|underwriter",
  "reason": "string",
  "available_data": { has_enrollment, has_claims, has_matches }
}
```

#### POST /api/cases/{case_id}/auto-save
Auto-save field changes:
```typescript
Body: { "field": "string", "value": any }
Response: { "success": true, "timestamp": "datetime", "field": "string" }
```

#### GET /api/cases/{case_id}/export
Export case report:
```typescript
Query: { "format": "pdf|xlsx|csv" }
Response: File download
```

## Troubleshooting

### Data Not Loading
- Check API endpoint is accessible: `GET /api/cases/{id}/detail`
- Verify authentication token is present
- Check browser console for CORS errors

### Auto-Save Not Working
- Verify localStorage is available
- Check browser permissions
- Inspect network tab for 429 (rate limit) errors

### Workflow Stuck
- Check case status in database: `db.cases.findOne({case_id: "..."})`
- Verify background jobs are running: `ps aux | grep uvicorn`
- Check logs: `tail -f /home/ubuntu/goisure/backend/gmc_backend.log`
